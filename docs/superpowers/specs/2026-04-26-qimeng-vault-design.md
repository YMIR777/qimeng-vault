# 小黒秋的大金库 — 产品设计文档（v2.0）
> 版本：v2.0 | 日期：2026-04-26
> 更新说明：从 v1.0 架构审计后重新拆分页面，明确各页面心智模型

---

## 1. 项目概述

**名称**：小黒秋的大金库（绮梦账间）
**类型**：个人沉浸式财务管理 Web 应用
**愿景**：解决"陪玩"场景下的多渠道收入统计痛点，同时作为顶级个人开发作品集展示 WebGL 粒子特效能力
**核心卖点**：视觉仪式感 + 点云粒子交互 + 温暖极简主义
**定位**：个人深度自用 + 个人作品集展示

---

## 2. 页面架构（v2.0 核心变更）


## 3. Dashboard 页面

### 3.1 视觉布局

```
┌──────────────────────────────────────────┐
│  [☀️/🌙 日月切换]              [⚗️ 实验室] │
├──────────────────────────────────────────┤
│                                          │
│      ✨ 总资产数字（粒子汇聚）✨           │
│         ¥12,847.50                       │
│                                          │
│    [        魔法输入框        ]           │
│                                          │
│  🌱 灵种                        快捷记账  │
│  （左侧，小型）                  最近3笔   │
│                                          │
│  ──── 欲望进度条（极简1行）─────────    │
└──────────────────────────────────────────┘
```

### 3.2 核心组件说明

**总资产数字**
- 由粒子汇聚而成，粒子分形聚散
- 鼠标靠近产生引力反馈（推开效果）
- 数字变化时有"收缩-扩散"心跳震动

**魔法输入框**
- 页面最显眼位置，极简
- 逻辑：
  - 收入：`比心 150` → 自动识别平台=比心，金额=150，类型=收入
  - 支出：`打车 30` → 自动识别分类=交通，金额=30，类型=支出
- 回车后触发支出决策流程（见3.3）

**灵种（时薪生命体）**
- 位置：Dashboard 左侧，精简版，不抢戏
- 形态：粒子构成的树，从种子形态开始
- 成长：周均时薪越高，树越大（幼苗→开第一朵花→萤火虫环绕）
- 叶片颜色反映"值得/不值"比例
- 每次高时薪单子，少量金色粒子流向灵种

**账户余额快照**
- 简洁列表形式（招行/微信/支付宝/现金/建行）
- 每次收入/支出自动同步更新
- 非星团可视化（星体页承载"账户感"）

**欲望进度条**
- Dashboard 底部，极简一行
- 显示当前最活跃星体的进度（不喧宾夺主）

## 4. 欲望星体页面

### 4.1 整体视图（星系展示）

所有星体以星系形式呈现，随进度从虚幻粒子轮廓→凝实。

### 4.2 单星体详情

点击星体进入详情：
- 星体名称（如"iPhone 17 Pro 1TB"）
- 目标金额 / 已存入金额
- 存入/取出操作
- 与该星体相关的收支记录

### 4.3 存入机制（Mode B：星体=独立账户）

- 记账时可选择"存入星体 X"
- 星体有独立余额，显示"已存入 ¥X / 目标 ¥Y"
- 星体余额增加 → 星体凝实度提升
- 用户从星体"取出"使用 → 星体退步
- **即使总资产下降，只要星体没被动，星体进度不受影响**

### 4.4 多星体管理

- 超出可视区域时：水平滚动
- 支持自定义多个星体（像许愿瓶）
- 达成后：可交互内容 → 庆祝动画 → 移入"已达成"区域（可视化成就）

## 5. 支出决策流程（能量守恒）

```
用户输入支出 → 瓦解为粒子流 → 悬浮律动（1.5s）

→ 检查 judgment_patterns 表：
    ├─ 连续≥2次同一判断 → 自动归类（静默入账，无动画）
    └─ 无历史 / 需确认 → 显示左右感应区

左侧 [灵感/价值] → 粒子金光化 → 飞向总资产 → 数字心跳扩散
                → 若关联星体 → 同时粒子飞向目标星体

右侧 [损耗/虚度] → 粒子灰褐色 → 向屏幕深处流失 → 总资产数字颤抖
```

**收入逻辑**：直接粒子撞击总资产，无需选择。

**撤销**：支持，操作失误可撤回。

## 6. 收入工作台页面

### 6.1 展示数据（有实际意义的生产力数据）

- **时薪趋势**（周/日视图）—— 知道自己什么时候生产力最高
- **来源分布** —— 各平台/来源金额占比，知道钱从哪来
- **本周 vs 上周对比** —— 趋势一目了然
- **平均单笔金额** —— 知道自己一单大概多少钱

### 6.2 来源标签（Source Tagging）

- 记账时自动记忆输入过的来源（比心/微信/抖音/小红书）
- 输入首字母快速选择
- 目的：让你知道未来该去哪个平台发广告

### 6.3 时薪计算

- 记账时弹出时长滑块（1h/2h/3h）
- 公式：`RealHourlyRate = 净收入 / 陪玩时长`
- 系统自动计算，不强制展示

## 8. 粒子实验室

### 8.1 触发方式

右下角"实验瓶"图标，点击弹出毛玻璃质感面板。

### 8.2 可调参数

| 参数 | 范围 | 默认值 |
|------|------|--------|
| 粒子数量 (Count) | 50~2000 | 300 |
| 引力强度 (Gravity) | 0~100 | 30 |
| 阻尼系数 (Damping) | 0.8~0.99 | 0.95 |
| 粒子寿命 (Lifespan) | 1s~10s | 4s |
| 火花强度 (Spark) | 0~100% | 30% |
| 色彩映射 (Color) | 5种预设 | 星光深蓝 |

**色彩预设**：星光深蓝 / 极光紫 / 暖白墨黑 / 翠绿森林 / 琥珀暖金

### 8.3 日夜模式

日月切换**不在此设置**，放在顶部导航栏（高频按钮）。

## 9. 视觉系统

### 9.1 日夜双模

| 模式 | 背景色 | 粒子色 | 氛围 |
|------|--------|--------|------|
| 深夜模式（默认） | #0A0A0B（深藏青） | 自发光粒子（冰蓝+暖金双色） | 沉浸、神秘、科技感 |
| 暖白模式 | #F5F2ED（米白） | 深炭灰粒子（磨砂质感） | 清爽、专业、高效 |

### 9.2 字体

- **指定字体**：汉仪书宋二S（用户明确指定）
- 若字体加载失败，回退至衬线备选

### 9.3 粒子特效分层设计

- **主体粒子效果时**（数字汇聚、文字动画）：背景干净纯黑，无干扰
- **2D UI/文字内容时**：全屏粒子背景生效
- 避免粒子树（灵种）与全屏背景粒子视觉冲突

## 10. 数据模型（IndexedDB via Dexie.js）

```typescript
// 账户
interface Account {
  id: string
  name: string           // 招商银行卡 / 微信钱包 / 支付宝 / 现金 / 建行卡
  type: 'bank' | 'wechat' | 'alipay' | 'cash'
  balance: number        // 快照余额，每次收支自动同步
  createdAt: number
}

// 交易记录
interface Transaction {
  id: string
  type: 'income' | 'expense'
  amount: number
  category: string        // 支出分类 或 收入来源
  platform?: string      // 比心 / 微信 / 抖音 / 小红书 等
  bossName?: string      // 老板备注（仅代号）
  judgment?: 'worthy' | 'unworthy'  // 仅支出有
  timeSpent?: number     // 陪玩时长（分钟），用于计算时薪
  wishId?: string        // 关联星体ID（可选）
  note?: string          // 备注/心情/心得
  date: number           // 时间戳
  createdAt: number
}

// 支出习惯记忆（规则引擎）
interface JudgmentPattern {
  category: string
  consecutiveWorthy: number
  consecutiveUnworthy: number
  lastJudgment: 'worthy' | 'unworthy' | null
  autoSkip: boolean
}

// 欲望星体
interface Wish {
  id: string
  name: string           // e.g. "iPhone 17 Pro 1TB"
  targetPrice: number
  currentBalance: number  // 已存入金额（独立于总资产）
  status: 'building' | 'achieved' | 'withdrawn'
  createdAt: number
  achievedAt?: number
}

// 粒子实验室参数
interface ParticleSettings {
  count: number           // 默认 300，范围 50~2000
  gravity: number        // 默认 30，范围 0~100
  damping: number        // 默认 0.95，范围 0.8~0.99
  lifespan: number       // 默认 4s，范围 1~10
  sparkIntensity: number  // 默认 30%，范围 0~100
  colorTheme: string     // 默认 'deepBlue'
}
```

## 11. Preloader & Intro

### 11.1 流程

1. **Loading（3-5s）**：屏幕中央微弱光点（点云核心）随呼吸律动，背景渐变米色
2. **Entrance**：光点炸裂，粒子铺满屏幕，"小黒秋的大金库"由粒子汇聚而成
3. **Unlock**：点击任意位置，文字散开，Dashboard 模糊转清晰（Blur-to-Clear）缓缓浮现

### 11.2 触发规则

- 首次打开App：播放完整流程
- 后续打开：直接进入 Dashboard，有"跳过"选项（满足快速记账场景）
