# 小黒秋的大金库 — 产品设计文档
> 版本：v1.0 | 日期：2026-04-26

---

## 1. 项目概述

**名称**：小黒秋的大金库
**类型**：个人沉浸式财务管理 Web 应用
**愿景**：解决"陪玩"场景下的多渠道收入统计痛点，同时作为顶级个人开发作品集展示 WebGL 粒子特效能力。

**核心卖点**：视觉仪式感 + 点云粒子交互 + 温暖极简主义

## 3. 视觉系统

### 3.1 日夜双模

| 模式 | 背景色 | 粒子色 | 氛围 |
|------|--------|--------|------|
| 深夜模式（默认） | #0A0A0B（深藏青） | 自发光粒子（萤火虫感） | 沉浸、神秘、科技感 |
| 暖白模式 | #F5F2ED（米白） | 深炭灰粒子（磨砂质感） | 清爽、专业、高效 |

- 日夜切换按钮：顶部导航栏，精致丝滑滑块
- 不放在粒子实验室里（是高频按钮）

### 3.2 字体
- **指定字体**：汉仪书宋二S（用户明确指定）
- 若字体加载失败，回退至衬线备选

### 3.3 点云特效规范
- 全屏背景：持续粒子分形动画
- 数字展示：总资产由粒子汇聚而成
- Pretext：文字粒子聚散效果
- 鼠标悬浮：粒子产生位移扰动

## 4. 数据模型（IndexedDB via Dexie.js）

```typescript
// 账户
interface Account {
  id: string
  name: string           // 招商银行卡 / 微信钱包 / 支付宝 / 现金 / 建行卡
  type: 'bank' | 'wechat' | 'alipay' | 'cash'
  balance: number         // 手动更新的快照余额
  color: string           // 粒子色彩标识
  createdAt: number
}

// 交易记录
interface Transaction {
  id: string
  type: 'income' | 'expense'
  amount: number
  category: string        // 支出分类 或 收入来源
  platform?: string      // 比心 / 微信 / 抖音 / 小红书 等
  bossName?: string      // 老板备注（仅代号）
  judgment?: 'worthy' | 'unworthy'  // 仅支出有
  timeSpent?: number     // 陪玩时长（分钟），用于计算时薪
  note?: string          // 备注/心情
  date: number           // 时间戳
  createdAt: number
}

// 支出习惯记忆（规则引擎）
interface JudgmentPattern {
  category: string
  consecutiveWorthy: number
  consecutiveUnworthy: number
  lastJudgment: 'worthy' | 'unworthy' | null
  autoSkip: boolean
}

// 欲望目标
interface Wish {
  id: string
  name: string           // e.g. "iPhone 17 Pro 1TB"
  targetPrice: number
  currentProgress: number // 已积累金额
  status: 'building' | 'achieved'
  createdAt: number
}

// 粒子实验室参数
interface ParticleSettings {
  count: number           // 默认 300，范围 50~2000
  gravity: number         // 默认 30，范围 0~100
  damping: number         // 默认 0.95，范围 0.8~0.99
  lifespan: number        // 默认 4s，范围 1~10
  sparkIntensity: number  // 默认 30%，范围 0~100
  colorTheme: string      // 默认 'deepBlue'
}
```

## 5. 核心交互设计

### 5.1 支出决策流程（能量守恒）

```
用户输入支出 → 瓦解为粒子流 → 悬浮律动（1.5s）

→ 检查 judgment_patterns 表：
    ├─ 连续≥2次同一判断 → 自动归类（不触发选择）
    └─ 无历史 / 需确认 → 显示左右感应区

左侧 [灵感/价值] → 粒子金光化 → 飞向总资产 → 数字心跳扩散
                → 若为欲望支出 → 同时粒子飞向目标星体

右侧 [损耗/虚度] → 粒子灰褐色 → 向屏幕深处流失 → 总资产数字颤抖
```

**核心修正**：收入直接粒子撞击总资产，无需选择。

### 5.2 习惯记忆规则引擎

```typescript
function shouldTriggerDecision(category: string): boolean {
  const pattern = judgmentPatterns.get(category)

  if (pattern.consecutiveWorthy >= 2) return false  // 连续值得≥2次，跳过
  if (pattern.consecutiveUnworthy >= 2) return false  // 连续不值得≥2次，跳过
  return true
}

function recordJudgment(category: string, judgment: 'worthy' | 'unworthy') {
  // 记录并更新连续计数
}
```

**效果**：通勤、打车等固定消费2次后自动归类；奶茶、网购等诱惑性消费始终触发选择。

### 5.3 灵种（小树苗）时薪生命体

**位置**：Dashboard 左侧，与总资产平级
**视觉形态**：
- 🌱 第1周：幼苗，细枝+2-3片叶子
- 🌿 第2-4周：枝干长高，树叶茂密
- 🌳 第1个月：开第一朵花（高时薪里程碑）
- 🎄 长期：树冠饱满，萤火虫环绕

**状态反馈**：
- 树的大小 → 累计时薪（月均值，非实时）
- 树叶颜色 → "值得/不值得"比例（偏绿=消费观健康）
- 落叶飘散效果 → 偶尔出现，提醒不要冲动消费

**能量补给**：每次高时薪单子，金色粒子流向灵种。

**与欲望星体共生**：灵种越大 → 对 iPhone 17 星体引力越强，加速星体凝实。

### 5.4 欲望星体

**位置**：Dashboard 右侧，悬浮模块（独立区域）
**首个目标**：iPhone 17 Pro 1TB
**视觉变化**：随陪玩收入增加，从虚幻粒子轮廓 → 逐渐凝实
**支出联动**：选择"值得"且与目标相关的支出，粒子飞向星体使其更清晰

## 6. 粒子实验室

**触发**：右下角"实验瓶"图标，点击弹出毛玻璃质感的参数面板

**参数**：
| 参数 | 范围 | 默认值 |
|------|------|--------|
| 粒子数量 (Count) | 50~2000 | 300 |
| 引力强度 (Gravity) | 0~100 | 30 |
| 阻尼系数 (Damping) | 0.8~0.99 | 0.95 |
| 粒子寿命 (Lifespan) | 1s~10s | 4s |
| 火花强度 (Spark) | 0~100% | 30% |
| 色彩映射 (Color) | 5种预设 | 星光深蓝 |

**色彩预设**：星光深蓝 / 极光紫 / 暖白墨黑 / 翠绿森林 / 琥珀暖金

- 星团大小与余额比例成正比
- 点击星团可查看该账户详情

## 8. 开屏仪式（Preloader + Intro）

**流程**：
1. **Loading（3-5s）**：屏幕中央微弱光点（点云核心）随呼吸律动，背景渐变米色
2. **Entrance**：光点炸裂，粒子铺满屏幕，"小黒秋的大金库"由粒子汇聚而成
3. **Unlock**：点击任意位置，文字散开，Dashboard 模糊转清晰（Blur-to-Clear）缓缓浮现

---

## 9. 账户扣款逻辑

**简化方案**：
- 收入：默认入"主账户"（可指定）
- 支出：只记录金额，不强制选择账户
- 账户模块：仅展示各账户余额快照（手动更新初始值）
- 可选：手动标注"这笔从微信付的"作为备注（非强制）
