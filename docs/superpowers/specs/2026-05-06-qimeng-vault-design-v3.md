> 版本：v3.0 | 日期：2026-05-06
> 更新说明：放弃粒子系统，简化视觉路线，保留核心记账功能，视觉升级为暗金奢华风

## 1. 项目概述

**名称**：小黒秋的大金库（绮梦账间）
**类型**：个人功能性记账 Web 应用
**定位**：个人深度自用，专注"陪玩"场景多渠道收入统计
**核心原则**：功能驱动，视觉辅助，不做炫技动画

## 2. 视觉系统

### 2.1 色彩（暗金奢华）

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景 | #0D0D10 | 极深藏青，近黑 |
| 卡片背景 | #161619 | 微亮黑 |
| 卡片边框 | rgba(255,255,255,0.07) | 极淡白边 |
| 主文字 | #EEE8DC | 米白暖调 |
| 次文字 | #7A756E | 灰棕 |
| 强调色-蓝 | #4FC3F7 | 冰蓝，用于收入/正值 |
| 强调色-金 | #E8B84B | 暖金，用于支出/星体/成就 |
| 成功/值得 | #6DBF82 | 柔绿 |
| 损耗/不值 | #D97373 | 暗红 |

### 2.2 字体

- **标题/数字**：Noto Serif SC（衬线，温暖）
- **正文/UI**：Noto Sans SC（无衬线，清晰）
- **回退**：系统默认

### 2.3 间距与布局

- 大量留白，不拥挤
- 卡片圆角 16px
- 内边距 20-28px
- 无英雄式布局，每个模块都是信息单元
- 底部 Tab 导航（不是侧边栏）

### 2.4 微交互（替代粒子）

- 按钮/卡片 hover：微微上浮 + 金色边框亮起
- 数字变化：数字本身滚动动画
- 值得/不值选择：左右滑动 + 颜色渐变过渡
- 无 WebGL/无复杂粒子，视觉质感靠 SVG + CSS 实现

## 4. 核心功能详情

### 4.1 魔法输入框

**输入格式（宽松兼容）**：
```
比心 150          → 收入，比心平台，150元
微信老板转200     → 收入，微信，200元
打车30            → 支出，交通，30元
吃饭花了45        → 支出，餐饮，45元
```

**识别逻辑**：
- 关键字匹配：含"比心"→平台=比心，含"微信"→平台=微信，含"老板"→收入
- 含"转/收到/收入" → 收入
- 含"花了/支出/买/消费" → 支出
- 数字提取：全部数字，取最大值为金额
- 无法识别 → 进入默认"支出"让用户手动选择

**回车后**：进入支出决策流程（如果判定为支出）

### 4.2 支出决策流程（能量守恒）

```
输入支出 → 选择"值得" 或 "不值"

值得：
  - 卡片边框变绿金光晕
  - 存入欲望星体（可选择关联哪个星体）
  - 更新总资产

不值：
  - 卡片边框变暗红
  - 数字微颤抖动画
  - 不关联星体
```

**习惯记忆**：连续2次同类判断 → 第3次自动跳过（静默入账）

### 4.3 欲望星体（SVG 许愿瓶）

**视觉**：每个星体是一个 SVG 瓶形图，内有发光进度填充
- 进度通过金/蓝色渐变填充瓶身表示
- 未达成：轮廓淡灰色
- 进行中：蓝色填充 + 微光
- 已达成：金色填充 + 爆发光效

**交互**：
- 存入：从魔法输入框记账后选择关联星体，或在工作台手动存入
- 取出：在星体详情页点击"取出"，填写取出金额
- 达成：达到目标金额 → 庆祝动画（金色光晕扩散）→ 移入"已达成"区域

**多星体**：超出显示区域时水平滚动

### 4.4 灵种/时薪树（2D 视觉）

**视觉**：一棵简化 SVG 树的生长过程
- 第1周：幼苗（2-3片叶子）
- 第2-4周：枝干长高，树叶茂密
- 第1个月：开第一朵花（里程碑）
- 长期：树冠饱满，萤火虫点缀

**生长逻辑**：
- 基于"周平均时薪"变化
- 时薪提升 → 树变大/变亮
- 每周日自动计算周均时薪，决定是否"蜕变"

**显示位置**：Dashboard 左侧侧栏，占一个小角落，不喧宾夺主

### 4.5 多账户管理

**账户列表**：
- 招商银行卡 / 微信钱包 / 支付宝 / 现金 / 建行卡
- 每账户显示：名称 + 当前余额
- 每次收入/支出后同步更新所有账户余额

**账户操作**：
- 收入：默认入"主账户"（招行），可手动选择
- 支出：从总资产扣减，不强制选择账户（但可备注"从微信付的"）

### 4.6 来源标签

- 记账时自动记忆输入过的来源（比心/微信/抖音/小红书）
- 输入首字母快速选择
- 用于来源分布统计

### 4.7 收入工作台

**数据展示**：
- 时薪趋势（周视图折线图）
- 来源分布（各平台金额占比）
- 本周 vs 上周对比（增减百分比）

### 4.8 日报/周报简报

- 每日/每周首日自动生成
- 内容：本期收入合计 / 支出合计 / 净增 / 高光单子 / 离目标差距
- 卡片形式展示，简洁清晰

## 5. 数据模型（IndexedDB via Dexie.js）

```typescript
// 账户
interface Account {
  id: string
  name: string
  type: 'bank' | 'wechat' | 'alipay' | 'cash'
  balance: number
  createdAt: number
}

// 交易记录
interface Transaction {
  id: string
  type: 'income' | 'expense'
  amount: number
  category: string        // 支出分类 或 收入来源
  platform?: string      // 比心/微信/抖音/小红书
  bossName?: string      // 老板备注（仅代号）
  judgment?: 'worthy' | 'unworthy'
  timeSpent?: number     // 分钟
  wishId?: string        // 关联星体ID（可选）
  note?: string
  date: number
  createdAt: number
}

// 星体
interface Wish {
  id: string
  name: string
  targetPrice: number
  currentBalance: number  // 已存入金额
  status: 'building' | 'achieved' | 'withdrawn'
  createdAt: number
  achievedAt?: number
}

// 支出习惯
interface JudgmentPattern {
  category: string
  consecutiveWorthy: number
  consecutiveUnworthy: number
  lastJudgment: 'worthy' | 'unworthy' | null
  autoSkip: boolean
}

// 简报
interface Report {
  id: string
  type: 'daily' | 'weekly'
  date: number
  income: number
  expense: number
  net: number
  topTransactions: string[] // ids
  wishProgress: { wishId: string; progress: number }[]
}
```

## 6. 技术栈

| 类别 | 技术 |
|------|------|
| 框架 | React + Vite + TypeScript |
| 样式 | CSS Variables + CSS Modules（无 Tailwind） |
| 图表 | Recharts（简单折线/饼图） |
| 本地存储 | IndexedDB (Dexie.js) |
| 字体 | Noto Serif SC + Noto Sans SC |
| SVG | 内联 SVG（星体树/图标），无外部依赖 |
| 无动画库 | CSS transition 够用，不引入 GSAP/R3F |
