## 一、产品愿景

**核心理念：** 记账是记录存在，不是批判消费。财务软件应该是镜子，不是鞭子。

**目标用户：** 小黒秋（19岁，学生/陪玩，月生活费 ¥1000）

**核心矛盾：** 收入极低但消费欲和自我批判强。通过记账建立"值得"的判断力。

### 错误修复
| 问题 | 根因 | 修复 |
|------|------|------|
| 清除数据无效 | 只清本地，sync 从云端拉回 | 同步删除 Supabase 数据 |
| 清除后钱包重复 | initDefaultAccounts 和 fullSync 竞态 | 顺序执行 |
| 推送数据始终 0 | PostgreSQL 列名自动小写 | 双引号包裹 camelCase |
| PWA 不更新 | autoUpdate 不检测 | 自定义 SW + visibilitychange |
| 写入失败静默吞错 | 无 try/catch | 添加错误处理 + alert |

## 四、技术约束

- **前端：** React + TypeScript + Vite 8
- **存储：** Dexie.js (IndexedDB) + Supabase (PostgreSQL)
- **路由：** React Router v7
- **样式：** CSS Variables + Inline Styles（无 Tailwind）
- **动画：** CSS keyframes + GSAP
- **图表：** Recharts
- **字体：** Noto Sans SC + Noto Serif SC
- **部署：** Vercel（自动 hook GitHub push）
- **设计规范：** Taste-skill（V=8, M=6, D=4）
